# VP Aswin Kumar — Portfolio

A chess-themed 3D scroll portfolio. Static site: HTML, CSS and JavaScript, no build step.

- 3D: [three.js](https://threejs.org/)
- Scroll animation: [GSAP ScrollTrigger](https://gsap.com/) + [Lenis](https://lenis.darkroom.engineering/)
- Chess set model: "Chess Set" by Riley Queen, [Poly Haven](https://polyhaven.com/a/chess_set) (CC0)

## Run locally

```
python -m http.server 8000
```

Then open http://localhost:8000. (Opening `index.html` directly won't work: browsers block JavaScript modules from `file://`.)
